# Security

- Keep credentials in environment variables or ignored private configuration files.
- Never commit broker tokens, account data, session transcripts, memory files, uploads, or generated reports.
- Do not publish private information in issues, logs, screenshots, or examples.
- Run locally or behind appropriate authentication and network controls. This repository is not a hardened public multi-user deployment.
- Treat tool output and retrieved content as untrusted data. Approval rules and answer review are separate controls, not guarantees of safe or correct model behavior.
- If a credential is exposed, revoke or rotate it at the provider; deleting a file does not revoke access.

For a suspected vulnerability, use GitHub private vulnerability reporting if enabled. Do not include exploit credentials or personal financial data in a public issue.
